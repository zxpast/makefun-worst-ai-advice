One line of the worst possible advice an AI could give, in 140 characters
or fewer — written by a program for the make.fun competition
"Worst AI Advice: The 48-Hour Tight Line Open".

## Layout

- `main.ts` — the entrypoint: writes the one-liner to `/output/entry.txt`.
- `.makefun/owner.json` — the payout wallet for this entry.

## Run it

```sh
node main.ts
```

It writes exactly one line (87 characters, no trailing newline) to
`/output/entry.txt`. Deterministic: every run produces byte-identical
output.
